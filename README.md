# loongMusic 音乐播放器

一个零依赖、单文件的在线音乐播放器。从 yinyueku.cn 实时获取资源，支持搜索、播放、歌词、本地歌单与下载。

## 特性

- **双击即用**：无需 Python、无需启动服务，双击 HTML 即可听歌
- **HTTPS → HTTP 自动降级**：站点证书过期导致 HTTPS 失败时，自动改用 HTTP 重试一次（站点证书修复后该逻辑自然失效）
- **流畅播放**：点击即播，播放完自动下一首，失败自动跳过（连续 3 次后停止）；网易云 / QQ 音乐双源互补
- **播放控制**：播放/暂停、上/下一首、可跟手拖动的进度条、音量记忆、顺序 / 单曲循环 / 随机
- **歌词**：LRC 解析、逐行高亮滚动、点击歌词跳转进度
- **在线歌单同步**：填入网易云 UID 或 QQ 号，一键把该账号的公开歌单列表同步到侧边栏；点开任意歌单即拉取歌曲播放，可整单导入为本地歌单
- **本地歌单**：新建 / 重命名 / 删除歌单，收藏歌曲入库（localStorage 持久化）
- **最近播放 & 下载**：取直链保存为 mp3（浏览器下载范围内实现，失败自动降级新标签手动保存）
- **移动端适配**：竖屏顶栏 / 播放条改多行网格布局，≥320px 宽度下任何功能键都不溢出、不遮挡；触屏设备的收藏 / 下载等按钮常显（不再依赖悬停）；适配刘海屏安全区
- **媒体键**：接入 MediaSession，支持系统媒体控制

## 技术架构

| 层 | 实现 |
| --- | --- |
| 前端 | 原生 HTML / CSS / JavaScript，单文件 `音乐播放器.html`，无框架无构建 |
| 播放 | `<audio>` 标签播放 mp3 直链（媒体不受跨域限制） |
| 本地服务 | `server.py`，仅用 Python 标准库，零第三方依赖 |
| 请求 | `file://` 直开走 JSONP（默认）→ HTTPS 失败自动降级 HTTP；若由本地服务提供页面则走同源 `/api` 代理 |
| 持久化 | `localStorage`（音量、播放模式、歌单、最近播放） |

> **关于站点证书**：数据源 `www.yinyueku.cn` 的 TLS 证书已过期（TrustAsia DV，notAfter 2025-08-12），浏览器 / curl 直连 HTTPS 会以 `net::ERR_CERT_DATE_INVALID` 失败。该站虽返回 `Strict-Transport-Security` 头，但因 HTTPS 从未成功访问过，HSTS 并未写入生效，HTTP 仍可正常取数。
> 因此请求层做了 **HTTPS → HTTP 自动降级**：先发 HTTPS，失败且页面自身非 HTTPS（`file://` / `http://`）时改用 HTTP 重试一次。站点证书一旦修复，HTTPS 首次尝试即成功，降级分支自然不再执行。双击 HTML 即可使用，无需启动任何服务。

## 快速开始

### 方式一：直接双击（推荐）

直接双击 **`音乐播放器.html`**，在搜索框输入歌名 / 歌手，点击歌曲即播。无需 Python、无需启动任何服务。

请求会先尝试 HTTPS，证书过期时自动降级到 HTTP（页面会提示一次「已改用 HTTP 连接」）。歌单、最近播放等数据存于浏览器 localStorage。

### 方式二：本地代理（可选）

若 HTTP 也被网络环境屏蔽，可用本地代理中转（代理转发时跳过上游证书校验）。前置：已安装 Python 3（仅用标准库）。

1. 双击 **`启动播放器.bat`**
   - 自动启动 `server.py`（默认 `http://127.0.0.1:8964/`），并打开浏览器进入播放器
   - 若系统 Python 未找到，会回退到内置托管 Python 路径
2. 在搜索框输入歌名 / 歌手，点击歌曲即播
3. 关闭黑色控制台窗口（或按 Ctrl+C）即停止服务

也可手动启动（不自动开浏览器）：

```bash
python server.py --no-open
# 然后浏览器访问 http://127.0.0.1:8964/
```

> 两种方式的界面与功能完全一致；代理模式下页面由 localhost 提供，请求走同源 `/api`，不再触发降级逻辑。

## 使用说明

- 歌曲行悬停出现 **☆ 收藏 / ⬇ 下载**；收藏时选择歌单或新建歌单
- 左侧边栏：**在线歌单**、**最近播放**、**我的歌单**（悬停 ⋮ 可重命名 / 删除）；歌单页有「播放全部」
- **同步在线歌单**：点「在线歌单」右侧的 **＋**，选平台后填入账号 → 同步
  - 网易云音乐：填 **UID**（网页版「我的主页」地址栏中 `id=` 后面的数字）
  - QQ 音乐：填 **QQ 号**
  - 账号行可点击折叠 / 展开，悬停出现 **⟳ 重新同步** 与 **× 取消同步**；同步结果存于 localStorage，下次打开仍在
- 打开在线歌单后，顶部出现 **导入**：把该歌单整体存为本地歌单（此后即离线可用的本地数据）
- 底部播放条 ⬇ 可下载当前歌曲（浏览器直接保存，失败时自动开新标签手动 Ctrl+S）
- 空格键播放 / 暂停；右下角「歌词」展开歌词面板

## 移动端适配

界面以 **≥320px 竖屏** 为下限设计，实测覆盖 320 / 360 / 375 / 390 / 430 竖屏与 844×390 横屏：

- **顶栏与播放条改多行网格**：搜索框独占一行拿到完整宽度；播放条按「进度条 / 歌曲信息 / 播放控件 + 下载 + 歌词」三行排布。
  宽度不足时各行只是变窄，控件归属与顺序固定，不会互相挤压或叠在一起。
- **触屏不依赖悬停**：手机上没有 hover，歌曲行的收藏 / 下载、歌单的 `⋮`、账号的 `⟳` / `×` 一律常显可点。
- **触控目标放大**：可点元素不小于 40px，并加 `touch-action: manipulation` 去掉点击延迟。
- **安全区与动态视口**：`viewport-fit=cover` + `env(safe-area-inset-*)` 让开刘海与 Home Indicator；
  高度用 `100dvh` 跟随地址栏收展，界面不会被裁掉一条。
- **固定层不写死像素**：侧栏 / 歌词面板 / 提示气泡的位置，由脚本实测顶栏与播放条高度后写入 CSS 变量（`ResizeObserver`）决定。
- **收藏浮层**在移动端改为贴底弹层（浮动定位在窄屏容易顶到屏幕边缘）。
- **桌面布局不受影响**：移动端规则全部收在媒体查询内，≥881px 与改造前逐项一致。

> 移动端隐藏音量滑杆（沿用原有设计——音量交给系统硬件键），其余功能键一律保留。
> 另修正桌面端播放条右侧区域固定 150px 宽度、导致「歌词」按钮文字竖排与下载按钮被压扁的旧瑕疵。

## 已知限制与对策

- **直链有时效**：播放地址带 vkey，仅会话内缓存，过期即重新请求
- **sign 时效签名**：搜索结果携带 `sign`，请求 url/pic/lyric 必须带上；遇到「签名错误」会用「歌名 + 歌手」重新搜索换取新 sign 并重试（歌单旧歌签名失效可自愈）
- **部分源可能失败**：失败自动跳下一首；网易云 / QQ 双源互补
- **证书过期下的降级边界**：降级仅在页面自身非 HTTPS（`file://` / `http://`）时可用——HTTPS 页面加载 HTTP 子资源会被浏览器按混合内容拦截，因此若把本页部署为 HTTPS 站点，应保持 HTTPS 源可用或通过自带代理中转
- **JSONP 无状态码**：失败靠 `onerror` 与超时识别（HTTPS 尝试 8s、HTTP 尝试 15s），回调去重 + 节点回收，不会重复结算或悬挂
- **在线歌单单次上限 1000 首**：上游 `types=playlist` 接口单次最多返回 1000 首（`limit` 参数无效），超长歌单只会载入前 1000 首（界面会提示）
- **仅公开歌单**：账号把歌单设为隐私时读取不到；QQ 音乐返回的曲目数常与真实不符，以实际载入数量为准（载入后会回填修正）
- **在线歌单歌曲不落盘**：只持久化「账号 + 歌单目录」（体积小），歌曲按需实时拉取并做会话内缓存；想把歌单长期留住请用「导入」转成本地歌单
